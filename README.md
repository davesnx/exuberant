# Melange, Esy, Vite, React template

This template combines Melange with Esy and Vite for writing Reat applications.

## Benchmarks

[`bench/`](./bench) contains a hello-world web server benchmark comparing
Elysia (Bun), Dream, httpcats, httpun+eio, and http/af — see
[bench/README.md](./bench/README.md).
